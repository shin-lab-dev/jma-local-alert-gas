# jma-local-alert-gas

指定した市区町村の大雨・洪水に関する警報をメール通知する Google Apps Script です。

気象庁が公開している「気象警報・注意報」のデータを定期的に確認し、指定した市区町村で大雨警報、洪水警報、大雨特別警報などが発表され、状態が変化した場合にメールで通知します。

---

## このツールでできること

Google Apps Script（GAS）を使って、自分が住んでいる地域の防災気象情報を定期的に確認できます。

たとえば、次のような警報が発表された場合に、指定したメールアドレスへ通知します。

- 大雨警報
- 洪水警報
- 大雨特別警報

全国一律に通知するのではなく、**自分で設定した市区町村だけを監視する仕組み**です。

---

## 重要な注意事項

このプログラムは、気象庁や自治体などが発表する公式な防災情報を代替するものではありません。

このメール通知だけで避難等を判断せず、必ず以下のような公式情報も確認してください。

- 気象庁の防災情報
- 自治体からの避難情報
- 防災アプリ
- テレビ、ラジオ等の情報

気象庁 防災情報  
https://www.jma.go.jp/bosai/

---

## 使用するファイル

このリポジトリにある次のファイルを使用します。

`heavy-rain-alert.gs`

このファイルの内容を Google Apps Script に貼り付けて使用します。

---

## 最初に変更する場所

コードの最初に、次の設定部分があります。

```javascript
// 【1】通知を受け取るメールアドレス
const RECIPIENT_EMAIL = "ここにあなたのメールアドレス";

// 【2】都道府県名
const PREFECTURE_NAME = "福島県";

// 【3】市区町村名
const CITY_NAME = "福島市";

// 【4】気象庁の都道府県コード
const PREFECTURE_CODE = "070000";

// 【5】気象庁の市区町村コード
const CITY_CODE = "0720100";
```

基本的に変更するのは、この5か所です。

---

## 1. メールアドレスを変更する

たとえば、次のように自分が通知を受け取りたいメールアドレスへ変更してください。

```javascript
const RECIPIENT_EMAIL = "example@gmail.com";
```

---

## 2. 都道府県名・市区町村名を変更する

たとえば福島市で使う場合は、次のようになります。

```javascript
const PREFECTURE_NAME = "福島県";
const CITY_NAME = "福島市";
```

自分が監視したい地域へ変更してください。

---

## 3. 地域コードを変更する

このプログラムでは、気象庁が使用している地域コードを指定する必要があります。

設定するのは次の2つです。

```javascript
const PREFECTURE_CODE = "070000";
const CITY_CODE = "0720100";
```

福島県・福島市の場合は、

- 都道府県コード：`070000`
- 市区町村コード：`0720100`

となります。

自分の地域で利用する場合は、その地域のコードへ変更してください。

---

## 地域コードの調べ方

気象庁の「気象警報・注意報」のページから、自分の都道府県、市区町村を選択します。

気象庁 気象警報・注意報  
https://www.jma.go.jp/bosai/warning/

市区町村を選択した際のページやURL等から、地域コードを確認できます。

地域コードの確認が難しい場合は、気象庁の公開データや地域コード一覧を確認してください。

# Google Apps Scriptへの設定方法

## 1. Google Apps Scriptを開く

Googleアカウントにログインした状態で、Google Apps Scriptを開きます。

https://script.google.com/

「新しいプロジェクト」を作成してください。

---

## 2. コードを貼り付ける

最初から表示されているコードを削除し、このリポジトリの

`heavy-rain-alert.gs`

の内容をすべてコピーして貼り付けます。

---

## 3. 自分の地域に変更する

コードの冒頭にある5か所を変更します。

```javascript
const RECIPIENT_EMAIL = "ここにあなたのメールアドレス";

const PREFECTURE_NAME = "福島県";

const CITY_NAME = "福島市";

const PREFECTURE_CODE = "070000";

const CITY_CODE = "0720100";
```

---

## 4. 一度、手動で実行する

画面上部の関数選択欄から、

`checkHeavyRainRisk`

を選択します。

その後、「実行」を押します。

初回はGoogleから権限の確認が表示されます。

このプログラムでは、

- 気象庁のデータ取得
- メール送信

などを行うため、必要な権限を許可してください。

---

## 5. 動作を確認する

実行後、「実行ログ」を確認してください。

たとえば、警報が出ていない場合は、

```text
警報情報は更新されましたが、通知対象の警報はありません。
```

または、

```text
前回確認時から警報状態の変化はありません。
```

などと表示されます。

# 自動実行の設定

このプログラムは、Google Apps Scriptの「トリガー」を設定することで自動実行できます。

---

## 1. トリガーを開く

Google Apps Script画面の左側にある時計マークの

「トリガー」

を選択します。

---

## 2. トリガーを追加する

画面右下の

「トリガーを追加」

を選択します。

---

## 3. 次のように設定する

実行する関数：

`checkHeavyRainRisk`

実行するデプロイ：

`Head`

イベントのソース：

`時間主導型`

時間ベースのトリガーのタイプ：

`分ベースのタイマー`

時間の間隔：

`20分おき`

最後に「保存」を押します。

これで、20分程度の間隔で自動的に気象庁の情報を確認します。

---

# 通知の仕組み

このプログラムは、毎回メールを送るわけではありません。

前回確認した警報の状態を Google Apps Script の `PropertiesService` に保存しています。

そのため、

- 警報が新たに発表された
- 警報の状態が変わった

場合に通知します。

同じ状態が続いている場合は、繰り返しメールを送らないようにしています。

# このツールを作った理由

大雨や豪雨のニュースを見るたびに、

「自分が住んでいる地域の危険度が上がったとき、メールで知らせてくれるだけでも違うのでは」

と思い、自分用として作成しました。

高度な防災システムではありません。

Google Apps Scriptと気象庁の公開情報を使った、小さな仕組みです。

自分で使ってみて、同じようなものが役に立つ方もいるのではないかと思い、地域を変更して利用できる形で公開しています。
